# ReelOS interface feature register

This register is the acceptance ledger for the personal-world interface. “Interactive preview” means the interface and local preview state can be reviewed; it does not claim that a production service performed playback, filtering, installation, security enforcement, synchronization, or learning.

## Automatic engine behavior

These remain behind the interface and must not become ornamental Settings toggles: network selection and failover, storage pressure protection, resource limits, cache management, playback safeguards, request deduplication, recovery, and background synchronization. Their production evidence belongs in service tests and diagnostics, not in preview animation.

## Parked or non-consumer concepts

- Live TV and sports remain parked. `/guide` records the existing idea but is not part of the consumer milestone.
- Private fleet administration and low-level engine diagnostics remain outside the consumer interface.
- Recommendation previewing is deterministic curation over sample data. It is not a trained neural service and must not be presented as one.
- Installation, PIN enforcement, filtering/media transformation, playback, TorBox validation, party synchronization, device handoff, and acoustic calibration remain unverified until their live services report success.
