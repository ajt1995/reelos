# Install ReelOS 1.2

## Bootable ISO

`reelos-1.2.iso` — volume id **ReelOS 1.2**. GRUB default is **Install ReelOS 1.2**.

If the box has no ethernet, join Wi-Fi on the first screen **before** Ubuntu downloads anything. Extra packages are not fetched during autoinstall (that is what killed 1.1).

After reboot: console card, `http://reelos.local`.

Updates: GitHub `ajt1995/reelos`. Stack image pulls are a Settings toggle, default off.

Engines may only send work to the debrid adapter. No torrent client ships.

- USB: balenaEtcher, Rufus (DD mode), or `dd`.
- Default login: `reelos` / `reelos` — change it
- No indexers seeded. Do not fetch copyrighted media.
