# ReelOS

Install. Point. Stream.

This repo is the **OTA channel** for a house ReelOS box. The bootable ISO is not stored here (GitHub’s 2 GB release cap).

- Channel: [`channel.json`](./channel.json)
- Version: [`VERSION`](./VERSION)

The box checks this file on **Check for updates**. Stack images (Jellyfin, *arrs) stay frozen unless you enable the toggle.

No indexers are seeded. Do not fetch copyrighted media.
